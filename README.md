# Swift Limo

Static bilingual site for Swift Limo, a chauffeur service in Singapore.

- English: `index.html`
- Simplified Chinese: `zh/index.html`
- Shared styles: `css/styles.css`
- Quote form: `js/site.js` opens WhatsApp with the trip details and the fare notes

Serve the folder, then open the site:

```
python3 -m http.server 8765
```

The page is a night photograph, a cream body, and gold type. The words, the fleet photos, and the hero picture belong to this project.
